FAQ

Questions teams ask first.

Will it change things on its own?+

No. Our agents run supervised: they stage the update and an approver signs off in ServiceNow before any record is written.

Do we have to replace anything?+

No. It sits on top of the assignment rules, remediation target rules, flows and Service Graph Connectors you already have, and steps in only where they come up empty.

Can we trust what it says?+

Every proposal shows its reasoning and the source record for each fact, written to the work notes so it stays in the record's audit history.

What do we need to run it?+

The Security Operations agent is built on AI Agent Studio, so it needs Vulnerability Response and a Now Assist entitlement. Catalog Automation calls OpenAI with your own API key, so it needs no Now Assist SKU at all.
