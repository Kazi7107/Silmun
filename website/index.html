02How our agents work

The agent does the work. You make the call.

Every agent works the same way, in three steps.

Step 1Automatic It does the legwork. Reads your records, looks things up and drafts what should happen next.
Example

Turns "laptop for a new hire, MacBook or Dell" into a draft catalog item.

→
Step 2Needs your OK You check it. Nothing changes in ServiceNow until a person approves it.
Example

You review the draft, fix anything, then click Build Item.

→
AlwaysNever automated Big decisions stay with people. Some calls no agent of ours will ever make for you.
Examples

Approving a risk exception. Closing a vulnerability without scan proof.

Every step is logged on the record, so you can always see what the agent did and why.
