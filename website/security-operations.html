FAQ

Before you install it.

Will it change things on its own?+

No. It runs supervised: it stages the update and raises an approval, and nothing is written until an approver signs off. Exception requests are never auto-approved.

Do we have to replace anything?+

No. It works alongside your existing assignment rules, remediation target rules, remediation task rules and scanner integrations.

Which scanners does it work with?+

Any scanner already integrated with Vulnerability Response, such as Tenable, Qualys, Rapid7 and Tanium. It reads the detections and assets already imported, so it doesn't call the scanner directly.

Can we trust what it says?+

Every proposal shows its reasoning and the source record for each fact (CI relationship, detection, change record), journaled as a work note on the VI.

What do we need to run it?+

ServiceNow Vulnerability Response and a Now Assist entitlement that includes AI Agent Studio. Ownership tracing works best when your CMDB maps hosts to application services, CSDM style.
