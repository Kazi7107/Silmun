FAQ

Before you install it.

Will it build things without us?+

No. Nothing is written to sc_cat_item or its variables until you click Build Item.

Is our data safe?+

Only the description you type leaves your instance. No record data, user data or PII is sent, by design.

What will the AI cost us?+

Usually very little, and you can see it. Usage is metered per draft and billed to your own OpenAI account.

Do we need Now Assist?+

No. Catalog Automation calls OpenAI with your own API key, so you don't need a Now Assist SKU or AI Agent Studio.

Security details for your reviewer+
Sent to OpenAIOnly the description you type. No record data or PII, by design.
ConnectionOutbound REST over HTTPS (TLS 1.2+) to api.openai.com, only when you ask for a preview. Works through your AI proxy.
