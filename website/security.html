Security & Trust · for your reviewers

What our agents can touch, and what they can't.

This page is for your security and platform reviewers. Every Silmun agent is a scoped ServiceNow app, security-reviewed by ServiceNow before it's listed on the Store, and nothing it proposes is written until one of your approvers signs off.

Ask a security questionBook a demo

The rules

Four rules every agent ships with.

These hold for every agent we publish, whichever LLM it runs on.

01

Human-in-the-loop on every write.

Agents stage changes and raise an approval through the platform approval engine. An approver confirms anything that changes ownership, risk posture or your catalog before a record is written.

Staged→Requested→Approved
02

Some decisions are never automated.

Vulnerability exception requests are assembled with their evidence, but never auto-approved.

Exception requests: human only
03

Everything is journaled.

Every action is written to the work notes of the record it touched, with its reasoning and the source record behind each fact, so it stays in your activity stream and audit history.

work_notes · Vulnerability agent
cmdb_rel_ci: Payments API depends on lnx-pay-app-07
application service · support group = Linux Ops
04

Standard ServiceNow, from the Store.

Scoped applications, installed from the Application Manager, bound by the roles you grant and your ACLs and business rules. No external data store to keep in sync.

Scoped appYour roles & ACLsStore certified

Where your data goes

Two ways to run, stated up front.

Each agent either runs on ServiceNow's own LLMs or calls an LLM with your own key. Here's exactly what each one does.

Runs on Now AssistVulnerability Remediation
  • Built in AI Agent Studio and runs on ServiceNow's own LLMs, under your Now Assist entitlement.
  • Shows up in AI Control Tower alongside your other agents, and runs in supervised mode.
  • Reads the detections and assets already imported into Vulnerability Response. It doesn't call your scanner directly.
  • Requires Vulnerability Response and a Now Assist entitlement that includes AI Agent Studio.
See the agent →
Bring your own LLM keyCatalog Automation
  • Sent to OpenAI: only the description you type. No record data, user data or PII, by design.
  • Connection: outbound REST over HTTPS (TLS 1.2+) to api.openai.com, only when you ask for a preview. Works through your AI proxy.
  • Your key: stored encrypted in your instance, inside the app's scope. Never sent to the browser or written to system logs.
  • Audit: every generation request is logged. Nothing is written to sc_cat_item until someone clicks Build Item.
  • Releases: tested on Washington DC, Xanadu and Zurich.
